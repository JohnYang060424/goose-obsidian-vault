# Hermes 笔记管理最佳实践总结

> 通过分析 `obsidian-vault-us-ecs` 仓库总结，用于指导 Goose 的笔记管理策略。

## 1. 目录结构设计
Hermes 采用清晰的主题分类，Goose 可借鉴：
- **配置/**：API、服务器、工具参数（高优先级，直接保存）
- **工作流/**：自动化流程、集成指南
- **经验/**：排障记录、踩坑教训（中优先级，任务后总结）
- **偏好/**：用户习惯、设备清单

## 2. 笔记同步策略
- **本地与 GitHub 同步**：利用 Git 实现双向同步。
- **Obsidian 集成**：在 Windows 端使用 Obsidian 打开 Vault，配合 Git 插件自动 Commit/Push。
- **高价值信息**：API 密钥、IP、证书等信息直接入库。

## 3. 代理发现机制
Hermes 强调**在 Obsidian 笔记中搜索代理配置**。
- 代理配置通常记录在 `配置/` 或 `偏好/` 中。
- 遇到网络问题时，优先查阅 Vault 中的相关文档。

## 4. Goose 的适配
- 遵循 **第一原则**：所有文件严格限制在 `yang_goose_files` 下。
- 建立 `goose-obsidian-vault` 作为专用笔记库。
- 每次任务结束后，将关键配置和经验转化为 Markdown 笔记入库。

## 5. 双向链接
- 使用 `[[文件名]]` 建立笔记间的关联（如 `[[代理快速配置指南]]`）。
- 创建 MOC（Map of Content）作为索引入口。
